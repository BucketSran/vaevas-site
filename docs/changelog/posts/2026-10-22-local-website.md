# 搭建本地项目网站

在 `local/site/` 建了只在本机浏览的项目网站：介绍、EVAS、数学原理、Benchmark、Reference、模型成绩榜和更新日志七个栏目；对比表和数学手册从 main 自动导入，不在网站里另存一份。

<!-- more -->

## 做了什么

- 和用户确定栏目与范围：网站只在本地展示；语言用中文；介绍页去掉“宿主”；增加模型成绩榜（先空着）和更新日志（每次更新一条，可点进去看）。
- 用 MkDocs Material 1.6.1 / 9.7.7 搭建，源码放在仓库外的 `local/site/`，用本地 Git 记录历史。这样做是因为项目规则限制同时写入的工作区数量，而且 `local/` 本来就用来放本地展示材料。另外，任何会话都可以直接追加日志，不需要走分支和 PR。
- `tools/sync_main.py` 从 `origin/main` 只读导入四后端对比表的前五节、完整数学手册和对比评测标准，自动统计各后端的通过数，并把链接改成指向同一提交的 GitHub 文件。
- 数学原理另写了一页读者版（LaTeX 公式），每节链接到完整手册。
- Reference 栏目为 vaBench 各版建立统一格式：身份、构成、勘误表、修订版。规则是原件冻结、问题进勘误、修订另起版本号。
- 更新日志用 Material 的 blog 插件，历史条目按里程碑分组补写。以后每个会话结束时按 `local/site/README.md` 的步骤追加一条。

## 结果与证据

- 首次导入的来源是 main@deb5cf28（2026-10-21）。对比表前五节共 57 个用例，通过数为：EVAS 57、Spectre 48、Gnucap + modelgen-verilog 29、ngspice + OpenVAF-R 17。这些数字由脚本从原表统计，原表的口径限制同样适用。
- `./site.sh build` 依次做严格构建和构建后的站内链接、锚点检查。

## 遗留与下一步

- 许可没有定，需要用户决定（代码、题目数据、历史参考资料分别确定）。
- 模型成绩榜等正式清单录取题目后再填。
- 状态卡的数字靠手工维护，超过 14 天没更新会在页面上提醒。
