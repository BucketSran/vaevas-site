# 长期加速候选 #138：两个首切片合入，P14 切片 2 的阴性结果只存档

PR205（P03 首切片）和 PR207（P05 首切片）已合入 main，在固定合成请求上测得中位耗时下降；PR218 只把 P14 切片 2"无可测端到端收益"的结论和收据存进 main，代码不合入。所有数字只针对固定合成请求，不作 Spectre 速度或通用内存改善承诺。

<!-- more -->

## 做了什么

- PR205（P03，非线性历史 range 求值复用）：已接受的非线性历史步，其 range 求值按步身份和窗口 lo/hi 的位级键复用，写时复制时清空缓存。贡献、浮点顺序、误差包围和验收路径不变。合并提交 `35f8a3dc`。
- PR207（P05，事件窗口内复用电路组装结构）：结构变化时回退完整组装，每次仍按原 contribution 顺序重算所有数值；缓存不含候选电压、状态、算子值或证书。合并提交 `a0b87ea6`。
- PR218（P14 切片 2，算子条目逐个 `Arc` 共享）：把收据 `history-entry-sharing.json`（取自分支 `codex/p14-history-sharing-slice2` 的提交 `ec0ed05b`）和 `experiments/performance/README.md` 的一节说明合入 main。代码留在分支上，对应草稿 PR #212 不合并。

## 结果与证据

- P03：完整 JSON 请求各五轮交替、关闭诊断。nonlinear_idt 4097 点中位耗时 265.18 → 168.68 ms，8193 点 538.91 → 343.09 ms。代价是内存：内核子进程峰值 RSS 五轮最大值 6.75 → 7.75 MiB、8.92 → 11.09 MiB，缓存没有容量上限。7 例、140 次执行零失败，完整响应逐字节一致。
- P05：idt-8193 中位 150.78 → 141.18 ms；pwl_idt-8193 为 206.47 → 195.64 ms，后者范围仍有重叠，不报告为稳定提速。峰值 RSS 约 6.3–9.0 MiB，前后最大差小于 0.2 MiB。6 例、120 次执行零失败，完整响应逐字节一致。
- P14 切片 2：六个案例各 8193 个观察点，交替五轮共 120 次配置，新旧内核完整响应逐字节一致；移除的复制只占端到端约 1%，低于本机波动，记为"无可测差异"。数字来自 `e2c7aac7` 时的基线，测量期间主机有其他任务。
- 计时包含 Python 序列化、进程启动、内核读入/解析/求解/编码和 Python 解析，不含 VA 编译、checker 与归档。原始响应、逐轮数据和诊断为 local-only。PR205/207 的合并前和合并后 main CI 均通过；PR218 只改文档和一份已有收据，没有新增仿真或测量。

## 遗留与下一步

- P03 的缓存没有容量上限，不承诺任意长查询的内存上界。
- PR207 写明与当时未合并的 PR208 有共享事件路径冲突，后续整合须解决冲突并重验。
- P14 切片 2 代码不合入的原因：会让 PR208 在 `operators.rs` 上新增 10 处合并冲突（约 157 行），且与 Issue214 刚改过的历史复制计费重叠；若以后需要，等 PR208 合入后再在其上重放。
