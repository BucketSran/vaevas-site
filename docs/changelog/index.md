# 更新日志

每次更新是一条独立记录，点标题进去看详情。最新的在最上面；左侧可以按月份或分类（EVAS、Benchmark、项目）筛选。

每条记录的格式相同：摘要、做了什么、结果与证据、遗留与下一步、相关链接。数字都带口径。“开发中”的数字不是验收结论；“本地”“未推送”“草稿 PR”表示还没有合入 main。

!!! tip "怎么新增一条"
    会话结束时，让该会话总结本次工作，按[网站仓库 README](https://github.com/BucketSran/vaevas-site#add-changelog) 里“新增更新日志”一节的步骤追加一条。

!!! info "关于文中的本地路径"
    形如 `current/runs/...` 的路径是项目在本地保存的实验记录和证据，没有放进公开仓库。需要核对时请联系维护者。
